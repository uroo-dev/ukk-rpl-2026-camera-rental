WHY DONEZO

Built to be shipped, not just admired

Every asset is local, every component is documented, and every page shares the same navigation engine.

Fully self-contained

Tailwind CSS precompiled, Chart.js and Lucide vendored, fonts shipped as woff2. It runs on an intranet with no external requests.

Blade-ready markup

Semantic HTML with data attributes and vanilla JS helpers, so pages convert to Laravel partials without a bundler.

Copyable components

18 reference pages with preview and code tabs plus a one-click copy button for each snippet.

One navigation engine

A single script renders the sidebar on every page, detects the active route, and adapts to any folder depth.

Touch-first responsive

The sidebar becomes a drawer, tables scroll horizontally, and POS screens keep large tap targets.

One design language

Signature deep green, 1.5rem radii, soft card shadows, and consistent status pill colours across all modules.
